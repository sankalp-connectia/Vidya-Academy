# Vidya Academy images

- `school/` contains the optimized, scene-named photos supplied for the website.
- `heroes/<page>/desktop.webp` and `heroes/<page>/mobile.webp` are the separate hero frames for About, Programs, Campus, Motion-In, Events, and Achievements.
- `vidya-logo-transparent.png`, the mascot files, and `trividha-shikshana.webp` are shared brand artwork.

Export hero replacements at **1920 × 1080 px** for desktop and **900 × 1600 px** for mobile. Keep the subjects clear of the text overlay. The site selects the mobile file at **768 CSS pixels and below**.
