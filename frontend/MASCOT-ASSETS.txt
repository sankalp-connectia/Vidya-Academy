VIDYA ACADEMY — BRAND AND MASCOT ASSET MAP

Brand logos, mascot artwork, mascot animation, and the old project's school photos are included in the React code as defaults. Their bundled paths are set in the matching WordPress fields. Edit those fields in WordPress to replace an image or video.

OTHER WEBSITE PHOTOS
The matching default school photos from the old React project are bundled under public/images/ and assigned to the related WordPress image fields. If a field is blank, the frontend uses that bundled default. Upload/select a WordPress Media Library image or paste a hosted URL to replace it. New entries can be added in WordPress; when their image is blank, the matching section's bundled image is used where available.
